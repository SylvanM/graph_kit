# A Graph library for Rust

Various kinds of searches are really kinda the same thing,
but on different data structures. BFS, DFS, and Dijkstra can 
all be generalizations of the same tricolor algorithm. So,
a TODO in the future is to make the code for these algorithms
be sooo general. Like have one general "tricolor traversal" 
kind of iterator, and be able to just swap in data structures.
